QUICK START / 开始使用

三步开始管理文件

浏览、压缩、解压与预览都在同一个窗口完成，不必来回切换软件。

  1. 1

    打开软件

    从桌面或开始菜单启动简单压缩，左侧快速访问可以跳转到常用目录。

  2. 2

    压缩或解压

    选中文件后右键压缩，或直接打开 ZIP、7Z、RAR 等压缩包进行浏览与解压。

  3. 3

    预览与设置

    图片、PDF 与文本可直接预览；在「全局配置」中调整语言、主题与文件关联。
