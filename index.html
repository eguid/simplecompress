01 / 为何简单

把常用的几步，放进同一个窗口

不用为看文件、解压缩、预览文档分别打开不同的软件。打开简单压缩，就可以一直做下去。

01

一个窗口完成

浏览、压缩、解压、预览在同一个界面里衔接。少一次切换，就少一次重新找文件的打断。

02

无需额外软件

内置 ZIP、7Z、TAR 与 RAR / RAR5 处理能力，不用再安装 7-Zip 或 WinRAR，解压 RAR 也无需额外组件。

03

安装即用

提供 EXE 安装包，按提示完成安装即可使用，无需额外配置；个人非商业使用，条款清晰。

02 / 主要功能

从浏览到打包，
全程不用换窗口

该有的文件操作、压缩能力与预览格式都在这里，常用动作不必再借道别的软件。

下载后直接体验 →
01

文件管理

列表 / 缩略图两种视图，支持收藏、最近访问、搜索与常用文件操作；缩略图视图的内置图标右下角显示扩展名角标。

  • 双视图
  • 收藏
  • 最近访问
  • 搜索
  • 扩展名角标
02

压缩与解压

覆盖 ZIP、7Z、TAR、RAR / RAR5；JAR、WAR、APK、DOCX 等 ZIP 变体可直接浏览，加密 ZIP 会提示输入密码后解压。

  • ZIP
  • 7Z
  • TAR
  • RAR / RAR5
  • 加密 ZIP
03

多选操作

多个文件可合并为一个压缩包，格式与压缩率在弹框中一次选定；多个压缩包可同时解压到同一文件夹，或分别解压到独立文件夹。

  • 合并压缩
  • 同时解压
  • 分别解压
04

文件预览

内置图片、PDF、文本 / 代码 / SVG 查看器。图片支持 WebP、ICO、PSD、ICNS、TIFF（多页）等格式，图片与 PDF 支持滚轮按鼠标位置缩放和连续查看。

  • 图片
  • PDF
  • 文本 / 代码
  • 多页 TIFF
05

系统集成

可设置文件关联、资源管理器右键菜单，以及将本软件设为默认压缩程序；关联后的文件图标带扩展名角标。

  • 文件关联
  • 右键菜单
  • 默认压缩程序
06

个性化与设置

内置多种界面风格与多语言，可自由切换；临时解压目录可自定义，解压完成后可自动打开目标文件夹。

  • 多主题
  • 多语言
  • 临时目录
  • 完成后打开

04 / 使用场景

整理、交付、归档，都能顺手完成

不追求复杂的功能堆叠，只把每天都会遇到的文件操作做顺。

01 · 日常

把散落的文件收进一个包

多选文件后合并压缩，命名、格式与压缩率当场决定，不用先建文件夹再打包。

02 · 开发

直接浏览 ZIP 变体

JAR、WAR、APK 等文件打开即看，压缩包内还能增删文件，省去解压再重打的往返。

03 · 归档

老压缩包照样能解

RAR / RAR5 不再需要额外软件，遇到加密 ZIP 会提示输入密码，资料归档不断档。

04 · 分享

发出去之前先看一眼

图片、PDF、文本在窗口内直接预览，确认内容无误后再打包分享。

07 / 更新记录

每一次更新，都让操作更少一步

最近几个版本的变化。完整记录见项目 README。

  1. 0.8.12

    角标重复修复

    已关联格式的文件在文件管理器中不再显示两次角标——使用系统图标时不再叠加应用内角标，压缩包内部条目等内置图标仍正常补角标。

  2. 0.8.11

    中文名称统一 · 角标观感

    简体 / 繁体界面不再出现英文名称，窗口标题、对话框、关于页以及资源管理器中的程序名称统一使用「简单压缩 / 簡單壓縮」；文件管理器与资源管理器的角标样式重新校准，字体更清晰。

  3. 0.8.10

    启动优化 · 角标统一

    启动更快，首次启动实测约快 0.5～0.7 秒；文件管理器与资源管理器使用同一套角标样式，角标大小、字重与背景尺寸完全一致。

  4. 0.8.9

    角标样式统一

    资源管理器关联图标的角标以文件管理器缩略图角标为标准——字号、内边距与圆角按同一比例调整，常规字重、浅绿半透明背景、深绿文字。

  5. 0.8.8

    角标样式调整

    扩展名角标整体缩小，背景改为半透明浅绿、文字改为深绿，不再使用蓝底白字；图标过小时不显示角标。
