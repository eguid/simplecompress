# 简单压缩 · SimpleCompress

一款简单、免费、无广告、隐私安全的 Windows 文件管理与压缩工具

![版本 0.8.12](https://img.shields.io/badge/版本-0.8.12-blue?style=flat-square) ![平台 Windows](https://img.shields.io/badge/平台-Windows-0078D4?style=flat-square&logo=windows&logoColor=white) ![多语言 / 多主题](https://img.shields.io/badge/界面-多语言%20%2F%20多主题-purple?style=flat-square) ![个人非商业使用](https://img.shields.io/badge/许可-个人非商业使用-green?style=flat-square)

浏览文件、管理压缩包、预览常见文档，都可以在同一个窗口完成。

---

## ✨ 主要功能

- 📁 **文件管理**：列表 / 缩略图两种视图，支持收藏、最近访问、搜索与常用文件操作；缩略图视图的内置图标右下角显示扩展名角标
- 🗜️ **压缩解压**：支持 ZIP、7Z、TAR、RAR / RAR5，无需安装 7-Zip 或 WinRAR；JAR、WAR、APK、EAR、AAB、WHL、IPA、XPI、CRX 等文件可直接浏览，DOCX / XLSX / PPTX 也能当压缩包打开查看；遇到加密 ZIP 时会提示输入密码后解压
- 🗂️ **多选操作**：多个文件可合并为一个压缩包（弹框选择格式与压缩率），多个压缩包可同时解压到同一文件夹或分别解压到独立文件夹
- 👁️ **文件预览**：内置图片、PDF、文本 / 代码 / SVG 查看器，图片支持 WebP / ICO / PSD / ICNS / TGA / PCX / PNM / SGI / HDR / JPEG 2000 / TIFF（多页）等格式；图片与 PDF 支持滚轮按鼠标位置缩放和连续查看
- 🎨 **个性化**：内置多种界面风格与多语言，可自由切换
- 🔗 **系统集成**：可设置文件关联、资源管理器右键菜单，以及将本软件设为默认压缩程序；关联后的文件图标带扩展名角标
- 🛠️ **贴心设置**：可自定义临时解压目录、解压完成后自动打开目标文件夹

## 使用方式

- **安装方式**：下载 EXE 安装包，按提示完成安装

首次启动后可打开右下角「全局配置」调整语言、界面风格、临时目录等选项。
